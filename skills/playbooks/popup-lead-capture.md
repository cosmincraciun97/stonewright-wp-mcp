# Popup lead capture

## Steps
1. Discover form shortcodes with `stonewright/site-shortcodes-discover`.
2. There is no typed popup tool; `stonewright/theme-builder-apply-template` covers header, footer, single, archive, search-results, error-404 and loop-item templates only. Build the form section as a normal section with a validated spec and leave popup triggers and display rules to the user in the builder.
3. Keep copy short; one form, one CTA.
4. Snapshot templates before write.

## Rules
- Do not inject third-party scripts without user request.
