# Stonewright 1.0.0-alpha.91

## Figma to Elementor

- Add `stonewright/design-direction-brief`, a compact read-only ability that
  translates the active direction into deterministic Elementor layout,
  spacing, density, responsive, and motion guidance.
- Update the Figma workflow for both the official Figma MCP and Figma Console:
  read document metadata once, read tokens and styles once, then extract and
  normalize one section at a time instead of repeatedly carrying the raw Figma
  tree.
- Tighten the Elementor builder skill around measured responsive targets,
  native V3/V4 widgets, declared design tokens, first-section approval, and
  rendered evidence.

## Design Studio and Visual Workspace

- Add a four-step onboarding guide and keyboard-accessible contextual tooltips
  to Design Studio.
- Make readiness explicit: a direction cannot be ready with unresolved issues,
  and kit synchronization cannot be ready before the direction itself.
- Style the Visual Workspace post picker and editor controls with complete
  Stonewright button states.
- Open the real same-origin Elementor or block editor, wait for its runtime,
  and resolve the adapter against that editor window. The workspace still
  mounts immediately and truthfully reports disconnected state before an
  editor is attached.

## Abilities and gates

- The plugin exposes **330** abilities; Direct mode exposes **99** tools.
- The new direction brief is read-only and uses the normal design read
  permission.
- Existing Elementor permission, backup, confirmation-token, validation,
  audit, integrity, and typed-write gates remain unchanged.

## Package versions

- WordPress plugin and companion: `1.0.0-alpha.91`.
- `@stonewright/visual`: `0.4.0`.

## Verification

- Plugin unit, integration, contract, static-analysis, coding-standards,
  security, dependency, provenance, token, package, and documentation gates
  pass before tagging.
- Companion and Visual typechecks, tests, and builds pass before tagging.
- The WordPress admin Playwright matrix covers Design Studio and Visual
  Workspace across desktop, tablet, mobile, light, dark, keyboard, and
