# Stonewright 1.0.0-beta.16.2

Released: 2026-10-13

Release channel: `supported`

## Summary

This supported public beta lets you hide the Stonewright entry in the menu on
the left of the dashboard, and handles a second Stonewright copy installed in
another plugin folder. Plugin and companion stay aligned on `1.0.0-beta.16.2`;
Stonewright Visual stays `0.4.0`.

## Added

- A **Show in admin menu** switch in **Stonewright → Setup → Settings**, under
  **Show in admin bar**. It is on by default. Turned off, the Stonewright entry
  is hidden in the menu on the left of the dashboard. Every Stonewright page
  keeps its address, and the **Overview** and **Setup** links under Stonewright
  on the Plugins screen open them.
- A notice when Stonewright is installed twice, for example after uploading the
  ZIP while the installed copy sits in another folder. When both copies are
  active, only one runs, and it can be the older one: the copy that does not run
  says so on the Plugins screen and the Dashboard, with both folders and
  versions. When one copy is active, the notice lists each folder, its version
  and the copy that runs.

## Fixed

- Deleting the second copy on the Plugins screen while the other copy runs no
  longer stops with a fatal error. Deleting one copy while another stays
  installed removes nothing: the list of registered widgets, the rescue helper
  and the data stay, also when the deleted copy is an older version.

## How to update

Open Dashboard → Updates, click Check again, and update Stonewright from
`1.0.0-beta.16.1`. Automatic updates can take up to about 24 hours to find and
install the release. The companion has no change besides its version; updating
its package reference to the published beta.16.2 asset is optional.

If Stonewright is installed twice, update the copy that runs first, deactivate
the other copy, then delete it on the Plugins screen.

Published assets are `stonewright-1.0.0-beta.16.2.zip`,
`stonewright-companion-1.0.0-beta.16.2.tgz`, and `SHA256SUMS.txt`.

## Compatibility and safety

- WordPress plugin and companion: `1.0.0-beta.16.2`.
- Plugin mode registers **397** abilities;
  Direct full exposes **105** tools.
- WordPress: 6.7 or newer.
- PHP: 8.1 or newer.
- Node.js: 20 or newer for the companion.
- Updates preserve existing memory, user skills, audit history, the change
  history, Direct state and connected OAuth clients.
