# Stonewright 1.0.0-beta.17.1

Released: 2026-10-19

Release channel: `supported`

## Summary

This supported public beta makes connecting an AI client easier on
**Stonewright → Setup**. The suggested server name and the MCP server URL now
stand out in each client's steps with a small copy button, and every OAuth guide
explains what to do when an organization manages the AI client. Plugin and
companion stay aligned on `1.0.0-beta.17.1`; Stonewright Visual stays `0.4.0`.

## Added

- Show the suggested server name and the MCP server URL inside the setup steps
  of each AI client on **Stonewright → Setup** as highlighted values with a
  small copy button next to them. The hosted apps (Claude.ai, Claude Desktop,
  ChatGPT), Claude Code, Codex, Zed, Gemini CLI, Other MCP clients and clients
  without published steps get them; Claude Code also gets a copyable command for
  signing in over SSH.
- Add a closed **Work account managed by an admin?** section to the OAuth guides
  on **Stonewright → Setup**. It says who can add a custom MCP server on
  organization plans, lists the admin steps with copyable values, shows a
  message for your admin with the server name and URL next to a **Copy message
  for your admin** button, and, where the client allows it, shows how to connect
  from your own computer instead, for example Claude Desktop with an Application
  Password or Claude Code.

## Companion

- Update the TOML parser (`smol-toml`) to 1.9.1.

## How to update

Open Dashboard → Updates, click Check again, and update Stonewright from
`1.0.0-beta.17`. Automatic updates can take up to about 24 hours to find and
install the release. Like `1.0.0-beta.17`, the plugin installs this update only
when the release's `SHA256SUMS.txt.sig` verifies against one of its release
keys. Updating the companion package reference to the published beta.17.1 asset
is optional.

Published assets are `stonewright-1.0.0-beta.17.1.zip`,
`stonewright-companion-1.0.0-beta.17.1.tgz`, `SHA256SUMS.txt` and
`SHA256SUMS.txt.sig`. To check them by hand, run this next to the downloaded
files:

```bash
sha256sum -c SHA256SUMS.txt
```

Then check the signature from a checkout of the `v1.0.0-beta.17.1` tag, with the
paths of the downloaded files:

```bash
node scripts/release-signature.mjs verify --manifest path/to/SHA256SUMS.txt --signature path/to/SHA256SUMS.txt.sig
```
