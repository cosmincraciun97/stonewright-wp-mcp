# Stonewright 1.0.0-alpha.89

## Fixed

- ChatGPT and other OAuth clients can complete administrator consent and return
  to the registered callback with an authorization code.
- The OAuth user entity now lives at its PSR-4 path, so Composer's authoritative
  production autoloader includes it in the release package.

## Abilities and gates

- No MCP ability was added, removed, renamed, or changed.
- OAuth redirect URI validation, PKCE, scopes, consent, authorization-code
  expiry, and permission checks remain unchanged.
- Existing backup, confirmation-token, design validation, and audit gates remain
  unchanged.
- The plugin exposes **329** abilities; Direct mode exposes **99** tools.

## Package versions

- WordPress plugin and companion: `1.0.0-alpha.89`.
- `@stonewright/visual`: `0.4.0`.

## Verification

- The OAuth integration suite exercises the full approval path through
  authorization-code persistence and the ChatGPT callback.
- Plugin unit, integration, and contract suites; static analysis; coding
  standards; security, dependency, provenance, token, package, and
  documentation gates; companion and Visual typechecks, tests, and builds; and
  the full browser matrix pass before tagging.
- Release ZIP and companion tarball contents and SHA-256 checksums are verified
  before publication.

## Upgrade

Update both the WordPress plugin and local companion to `1.0.0-alpha.89`, then
restart the AI client so it loads the matching companion.
