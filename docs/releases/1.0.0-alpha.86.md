# Stonewright 1.0.0-alpha.86

## Fixed

- OAuth dynamic client registration accepts normal client requests that omit
  Stonewright's internal self-test header.
- Codex and other OAuth clients can complete registration instead of receiving
  an HTTP 500 response.
- The plugin exposes **324** abilities; Direct mode exposes **99** tools.

## Verification

- The regression test uses WordPress core's real missing-header behavior.
- The complete plugin, companion, documentation, and browser test gates must
  pass before this release is tagged.

## Upgrade

Update both the WordPress plugin and local companion to `1.0.0-alpha.86`, then
restart the AI client and retry OAuth sign-in.
