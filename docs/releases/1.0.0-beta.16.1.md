# Stonewright 1.0.0-beta.16.1

Released: 2026-10-13

Release channel: `supported`

## Summary

This supported public beta adds one setting: the Stonewright badge in the
toolbar at the top of WordPress can now be hidden. Plugin and companion stay
aligned on `1.0.0-beta.16.1`; Stonewright Visual stays `0.4.0`.

## Added

- A **Show in admin bar** switch in **Stonewright → Setup → Settings**, right
  under **AI abilities**. It is on by default. Turned off, the Stonewright status
  badge (ON, OFF, BLOCKED or ERROR) and its menu are removed from the toolbar of
  the dashboard and the site. The AI abilities keep their state, and the
  **AI abilities** switch still turns them on and off.

## How to update

Open Dashboard → Updates, click Check again, and update Stonewright from
`1.0.0-beta.16`. Automatic updates can take up to about 24 hours to find and
install the release. The companion has no change besides its version; updating
its package reference to the published beta.16.1 asset is optional.

Published assets are `stonewright-1.0.0-beta.16.1.zip`,
`stonewright-companion-1.0.0-beta.16.1.tgz`, and `SHA256SUMS.txt`.

## Compatibility and safety

- WordPress plugin and companion: `1.0.0-beta.16.1`.
- Plugin mode registers **397** abilities;
  Direct full exposes **105** tools.
- WordPress: 6.7 or newer.
- PHP: 8.1 or newer.
- Node.js: 20 or newer for the companion.
- Updates preserve existing memory, user skills, audit history, the change
  history, Direct state and connected OAuth clients.
