# Stonewright 1.0.0-alpha.85

## Highlights

- Browser-based OAuth for `/wp-json/mcp/stonewright-oauth`.
- PKCE, dynamic client registration, discovery, one-hour audience-bound access
  tokens, rotating fourteen-day refresh tokens, consent, revocation, and
  Connected Apps.
- OAuth-first setup instructions for 17 AI clients.
- Existing `/wp-json/mcp/stonewright` Application Password clients continue to
  work unchanged.
- The plugin exposes **319** abilities; Direct mode exposes **99** tools.

## Security

- Public plain HTTP sites do not expose OAuth.
- Redirect URIs, audience, scope, subject, registration limits, token replay,
  and refresh rotation fail closed.

## Upgrade

Install the plugin archive, open **Stonewright → Setup**, choose OAuth, select
the client, and approve the WordPress browser prompt.
