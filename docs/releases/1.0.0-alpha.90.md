# Stonewright 1.0.0-alpha.90

## Fixed

- ChatGPT can scan and refresh the complete Stonewright MCP action surface.
- Empty nested input and output schema fragments now encode as JSON objects
  instead of invalid JSON arrays.
- The compatibility normalizer covers property schemas, array items, schema
  maps, conditional schemas, and composition keywords.

## Abilities and gates

- No MCP ability was added, removed, renamed, or behaviorally changed.
- Input and output contracts keep their existing permissive value semantics;
  only their JSON Schema representation changed.
- Existing permission, backup, confirmation-token, validation, and audit gates
  remain unchanged.
- The plugin exposes **329** abilities; Direct mode exposes **99** tools.

## Package versions

- WordPress plugin and companion: `1.0.0-alpha.90`.
- `@stonewright/visual`: `0.4.0`.

## Verification

- A registry-wide regression test serializes every public input and output
  schema and rejects schema fragments that are not JSON objects or booleans.
- Plugin unit, integration, contract, static-analysis, coding-standards,
  security, dependency, provenance, token, package, and documentation gates
  pass before tagging.
- Companion and Visual typechecks, tests, and builds pass before tagging.
- Release ZIP and companion tarball contents and SHA-256 checksums are verified
  before publication.

## Upgrade

Update the WordPress plugin and companion to `1.0.0-alpha.90`. In ChatGPT,
refresh the custom app actions or recreate the development app so it scans the
corrected schemas.
