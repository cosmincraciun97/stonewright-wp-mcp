# Stonewright 1.0.0-beta.13.3

Released: 2026-09-17

Release channel: `supported`

## Summary

This supported public beta selects the MCP adapter the live autoload chain
actually loads, keeps status and audit faithful to the request that ran, and
stops ACF, Loop Grid, CSS, and stale-editor writes from reporting false
success. Plugin and companion stay aligned on `1.0.0-beta.13.3`. Visual remains
`0.4.0` and ships inside the plugin ZIP.

## Fixed

- Select the autoload-winning `wordpress/mcp-adapter` runtime instead of
  treating extra Composer mappings as an active conflict.
- Keep Direct fallback on typed plugin-route absence, split
  `/mcp/stonewright` from `/mcp/stonewright-oauth` in Setup, and treat
  “configuration verified, connection not tested” as info.
- Reject invalid ACF values before a no-op, repair a missing or wrong field
  key, and compute `changed` from before/after raw value and reference.
- Surface a Loop Grid compile failure after earlier steps already applied,
  keep partial effects visible, and refuse a full recreate.
- Treat only `text/css` HTTP probes as verified Elementor CSS delivery.
- Block a stale Elementor editor save after a later MCP write, keep the local
  draft, and leave `post_status` unchanged.
- Classify companion MCP routes from GET evidence and reject invalid WP-CLI
  `--url` values before spawn.

## Upgrade

Open Dashboard → Updates, click Check again, and update Stonewright from
`1.0.0-beta.13.2`. After the update, Plugins → View details must show this
release or a newer one, never a cached older body. Update the companion
package reference to the published beta.13.3 asset, fully restart the MCP
client, then run:

```bash
npx -y --package <published-companion-package> stonewright connect verify <alias> --client <client>
```

Success requires the requested alias, expected companion version,
`stonewright-task-start`, status availability, and an empty
`refresh_required_tool_names` list.

Published assets are `stonewright-1.0.0-beta.13.3.zip`,
`stonewright-companion-1.0.0-beta.13.3.tgz`, and `SHA256SUMS.txt`. Visual is
bundled in the plugin ZIP.

## Compatibility and safety

- WordPress plugin and companion: `1.0.0-beta.13.3`.
- Plugin mode registers **389** abilities; Direct full exposes **101** tools.
- WordPress: 6.7 or newer.
- PHP: 8.1 or newer.
- Node.js: 20 or newer for the companion.
- Updates preserve existing memory, user skills, audit history, and Direct state.
- Licensed Gravity Forms coexistence and the original Windows reporter host
  remain unconfirmed on this release.
