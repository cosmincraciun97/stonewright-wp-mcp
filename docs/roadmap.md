# Roadmap

Stonewright's near-term work prioritizes verifiable WordPress automation over a broader unguarded surface.

## Current

- Keep Plugin and Direct task-start contracts compact and evidence-based.
- Expand typed workflows only with the permission, backup, validation, readback, audit, and recovery coverage appropriate to the surface.
- Convert repeated failures into ranked incidents; promote audit-derived learning only after correlated verification.
- Keep installation to one guided Plugin path while retaining advanced multi-site, Direct, OAuth, WP-CLI, and browser choices.

## Next

- Publish client certification evidence as maintained acceptance reports.
- Extend restore coverage and independent verifiers across more typed write families.
- Improve local package distribution only after release metadata and updater channel behavior remain fail-closed.

## Explicitly separate

Website work, npm publication, version bumps, tags, and GitHub releases require their own approved tasks. Historical release assets remain immutable.
